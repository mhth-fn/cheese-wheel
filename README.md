# 🧀 Сырное Колесо Фильмов

Веб-приложение для совместного выбора фильмов с помощью колеса фортуны.

## Установка и запуск

### 1. Скопируй папку на сервер

```bash
scp -r cheese-wheel/ user@your-server:/path/to/app/
```

### 2. Установи зависимости

```bash
cd cheese-wheel
npm install
```

### 3. Собери фронтенд

```bash
npm run build
```

### 4. Запусти сервер

**Обычный запуск:**
```bash
npm start
```

**Режим разработки (Vite dev server + API proxy):**
```bash
npm run dev
```

**Фоновый режим:**
```bash
node server.js &
```

**Через PM2 (рекомендуется для продакшена):**
```bash
# Установка PM2 (один раз)
npm install -g pm2

# Запуск
pm2 start server.js --name cheese-wheel

# Автозапуск при перезагрузке сервера
pm2 startup
pm2 save
```

### 5. Открой в браузере

```
http://твой-сервер:3000
```

## Настройка порта

По умолчанию сервер запускается на порту 3000. Чтобы изменить:

```bash
PORT=8080 npm start
```

Или в PM2:
```bash
PORT=8080 pm2 start server.js --name cheese-wheel
```

## Функции

- **Авторизация** — выбор пользователя (Антон, Сергей, Пётр, Митя) + гостевой режим
- **Колесо фортуны** — добавление фильмов, вращение с анимацией и звуком, автоматический перенос в просмотренные
- **Просмотренные** — таблица с оценками от каждого пользователя, сортировка, поиск, статистика
- **Темы** — три визуальных темы (сырная, новогодняя, весенняя) с анимированными декорациями и тематической окантовкой колеса
- **Реалтайм** — синхронизация между вкладками через Socket.IO

## Бэкап базы данных

База хранится в файле `cheese_wheel.db`. Для бэкапа просто скопируй этот файл.

```bash
cp cheese_wheel.db cheese_wheel_backup_$(date +%Y%m%d).db
```
