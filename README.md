# 🧀 Сырное Колесо Фильмов

Веб-приложение для совместного выбора фильмов с помощью колеса фортуны.

## Локальный запуск

```bash
npm ci
npm run build
npm start
```

Для интерфейса разработки:

```bash
npm run dev
```

`npm start` и порт `3000` предназначены только для локальной разработки.

## Production

Production запускается только через [`ecosystem.config.js`](ecosystem.config.js)
от системного пользователя `cheese-wheel`, слушает `127.0.0.1:3000` и
публикуется через Nginx. Не открывайте Node-порт наружу и не запускайте
`server.js` от `root`.

Первичная защищённая установка и порядок миграции описаны в
[`deploy/README-security.md`](deploy/README-security.md). Первую миграцию нужно
выполнять целиком из root-shell, чтобы использовать тот же PM2 daemon и
прочитать закрытый `.env`:

```bash
sudo -i
cd /opt/cheese-wheel
git rev-parse HEAD
pm2 stop cheese-wheel
git pull --ff-only origin main
npm ci
npm run build
./deploy/install-security.sh
pm2 startOrRestart ecosystem.config.js --only cheese-wheel --update-env
pm2 save
```

Остановка до обновления файлов обязательна: так старая версия не запустится на
новом коде, а откатная копия базы будет содержать все последние изменения.

## Функции

- **Авторизация** — выбор пользователя (Антон, Сергей, Пётр, Митя) + гостевой режим
- **Колесо фортуны** — добавление фильмов, вращение с анимацией и звуком, автоматический перенос в просмотренные
- **Просмотренные** — таблица с оценками от каждого пользователя, сортировка, поиск, статистика
- **Темы** — три визуальных темы (сырная, новогодняя, весенняя) с анимированными декорациями и тематической окантовкой колеса
- **Реалтайм** — синхронизация между вкладками через Socket.IO

## Бэкап базы данных

На production база и загрузки автоматически сохраняются каждые шесть часов.
Копия SQLite создаётся через online backup API, затем проверяются целостность,
внешние ключи, архив загрузок и SHA-256. Подробности установки и восстановления:
[`deploy/README-backups.md`](deploy/README-backups.md).

Не копируйте работающий `cheese_wheel.db` обычной командой `cp`: база использует
WAL, поэтому такая копия может оказаться неполной.
