# 🧀 Сырное Колесо Фильмов

Веб-приложение для совместного выбора фильмов с помощью колеса фортуны и
общего дневника обзоров на кино, вино и музыкальные находки.

## Локальный запуск

```bash
npm ci
npm run build
npm start
```

Для интерфейса разработки:

```bash
npm run dev
```

`npm start` поднимает API на порту `3000`. Без `dist/` сервер разработки
намеренно отвечает `503` на страницы интерфейса — используйте Vite или сначала
выполните `npm run build`. В production отсутствие `dist/index.html` блокирует
запуск, поэтому старый интерфейс не может появиться вместо текущего.

Проверка перед публикацией:

```bash
npm test
npm run build
npm run test:browser
npm audit --omit=dev
```

Интеграционные тесты запускают настоящий сервер только на временной SQLite-БД
и случайном локальном порту. Browser smoke-test после сборки проверяет вход,
мобильную навигацию, переполнение интерфейса и минимальный контраст всех тем
в Chromium. Production-база им не доступна. Итог последнего полного прогона
зафиксирован в [`AUDIT.md`](AUDIT.md).

## Production

Production запускается только через [`ecosystem.config.js`](ecosystem.config.js)
от системного пользователя `cheese-wheel`, слушает `127.0.0.1:3000` и
публикуется через Nginx. Не открывайте Node-порт наружу и не запускайте
`server.js` от `root`.

Первичная защищённая установка и порядок миграции описаны в
[`deploy/README-security.md`](deploy/README-security.md). Первую миграцию нужно
выполнять целиком из root-shell, чтобы использовать тот же PM2 daemon и
прочитать закрытый `.env`:

```bash
sudo -i
cd /opt/cheese-wheel
git rev-parse HEAD
pm2 stop cheese-wheel
git pull --ff-only origin main
npm ci
npm run build
./deploy/install-security.sh
pm2 startOrRestart ecosystem.config.js --only cheese-wheel --update-env
pm2 save
```

Остановка до обновления файлов обязательна: так старая версия не запустится на
новом коде, а откатная копия базы будет содержать все последние изменения.

## Функции

- **Авторизация** — вход по уникальному имени и паролю, 2FA и гостевой режим
- **Приглашения** — администратор создаёт одноразовую ссылку, а новый участник сам задаёт пароль
- **Профиль** — смена имени-логина и пароля в меню пользователя
- **Колесо фортуны** — добавление фильмов, вращение с анимацией и звуком, автоматический перенос в просмотренные
- **ConQUIZtador** — одиночная территориальная викторина на `/conquiztador` с двумя ботами, замками и сохранением активной партии в браузере
- **Просмотренные** — таблица с оценками от каждого пользователя, сортировка, поиск, статистика
- **Темы** — сырная, новогодняя, весенняя и самурайская палитры с декорациями и тематическим колесом
- **Реалтайм** — синхронизация между вкладками через Socket.IO

## Бэкап базы данных

На production база, изображения и файлы паков SIGame автоматически сохраняются каждые шесть часов.
Копия SQLite создаётся через online backup API, затем проверяются целостность,
внешние ключи, архив загрузок и SHA-256. Подробности установки и восстановления:
[`deploy/README-backups.md`](deploy/README-backups.md).

Не копируйте работающий `cheese_wheel.db` обычной командой `cp`: база использует
WAL, поэтому такая копия может оказаться неполной.
