# 🧀 Сырное Колесо Фильмов

Веб-приложение для совместного выбора фильмов с помощью колеса фортуны.

## Установка и запуск

### 1. Скопируй папку на сервер

```bash
scp -r cheese-wheel/ user@your-server:/path/to/app/
```

### 2. Установи зависимости

```bash
cd cheese-wheel
npm install
```

### 3. Запусти сервер

**Обычный запуск:**
```bash
npm start
```

**Фоновый режим:**
```bash
node server.js &
```

**Через PM2 (рекомендуется для продакшена):**
```bash
# Установка PM2 (один раз)
npm install -g pm2

# Запуск
pm2 start server.js --name cheese-wheel

# Автозапуск при перезагрузке сервера
pm2 startup
pm2 save
```

### 4. Открой в браузере

```
http://твой-сервер:3000
```

## Настройка порта

По умолчанию сервер запускается на порту 3000. Чтобы изменить:

```bash
PORT=8080 npm start
```

Или в PM2:
```bash
PORT=8080 pm2 start server.js --name cheese-wheel
```

## Структура файлов

```
cheese-wheel/
├── package.json      # Зависимости
├── server.js         # Бэкенд (Express + SQLite)
├── public/
│   └── index.html    # Фронтенд (всё в одном файле)
└── cheese_wheel.db   # База данных (создаётся автоматически)
```

## Функции

- **Авторизация** — выбор пользователя (Антон, Сергей, Пётр, Митя)
- **Колесо фортуны** — добавление фильмов, вращение, автоматический перенос в просмотренные
- **Просмотренные** — таблица с оценками от каждого пользователя, сортировка по любому столбцу

## Бэкап базы данных

База хранится в файле `cheese_wheel.db`. Для бэкапа просто скопируй этот файл.

```bash
cp cheese_wheel.db cheese_wheel_backup_$(date +%Y%m%d).db
```
